# 진(DJINN)-lite — 토끼풀용 공공데이터 취재 알림 봇

노르웨이 트롬쇠 지역신문 이트롬쇠가 만든 AI 취재지원 시스템 '진(DJINN)'을 참고해,
학생 언론 토끼풀 규모에 맞게 축소한 버전입니다. 자체 훈련 모델 세 개 대신 범용 LLM
한 번 호출로 "이 공고, 기사감일까?"를 판단해 상/중/하로 표시합니다. 원본 진
시스템과 마찬가지로 **AI는 기사를 쓰지 않습니다.** 취재 단서를 찾아서 우선순위를
매겨줄 뿐이고, 실제 취재·검증·기사 작성은 학생 기자가 합니다.

지금 단계는 분류 기준 자체를 검증하는 중이라, 우선순위와 상관없이 새 글을
전부 슬랙에 올립니다 (`config.MIN_PRIORITY_TO_POST = "하"`). 절차성 공고까지
사람이 직접 눈으로 훑고 👍/👎로 판정해야 어떤 기준이 맞는지 알 수 있기
때문입니다. 편집진의 취재 범위도 은평구로 좁히지 않습니다 — 토끼풀이 그동안
다뤄온 주제 자체가 기후동행카드·K-패스 청소년 배제 정책처럼 서울 전역·전국
단위인 경우가 많아서, 분류 기준(`djinn_lite/classify.py`)도 지역이 아니라
"청소년 삶에 규칙 변화 수준의 영향을 주는가"를 기준으로 판단합니다.

## 지금 감시하는 곳

- 서울특별시교육청 공지사항 (`www.sen.go.kr`)
- 서울특별시교육청 보도자료 (`enews.sen.go.kr`)

다른 게시판(은평구청 고시공고 등)을 추가하고 싶으면 `djinn_lite/sources.py`에
같은 형태의 함수를 하나 더 만들고 `fetch_all()`에 연결하면 됩니다.

## 매일 아침 벌어지는 일

1. 어제 이전에 슬랙에 올려둔 알림들의 👍(기사감)/👎(아니다) 반응 개수를 세어
   `state/feedback_log.csv`에 기록합니다. (나중에 분류 기준을 다듬을 근거 데이터)
2. 두 게시판에서 최근 글을 가져와, 이미 처리한 글(`state/seen.json`)은 걸러냅니다.
3. 새 글들을 한꺼번에 LLM에 보내 "상/중/하" 우선순위와 이유를 받습니다.
4. (지금 단계는) 우선순위와 상관없이 전부 슬랙 `#진-알림` 채널에 올리고,
   👍/👎 반응을 미리 달아둡니다. 분류 기준이 충분히 검증되면
   `config.MIN_PRIORITY_TO_POST`를 "중"으로 올려 절차성 공고를 자동으로
   숨기는 것을 검토하세요.
5. 바뀐 상태 파일을 저장소에 다시 커밋합니다 (GitHub Actions가 매번 새 컨테이너로
   뜨기 때문에, 이렇게 저장소 자체를 "기억 장치"로 씁니다).

## 시작하는 방법

### 0. 이 폴더를 GitHub 저장소로 올리기

기존 토끼풀 저장소가 있다면 이 폴더 전체를 그 안의 하위 폴더로 넣어도 되고,
새 저장소를 만들어도 됩니다. 새로 만든다면:

```bash
cd tokipul-djinn-lite
git init
git add .
git commit -m "init: 진(DJINN)-lite"
git branch -M main
git remote add origin <새로 만든 저장소 URL>
git push -u origin main
```

### 1. 슬랙 앱 만들기 (알림을 보내려면 반드시 필요)

이 세션에서 미리 `#진-알림` 채널(`C0BRLQBLGR3`)을 만들어두고 안내 메시지를
올려뒀습니다. 하지만 자동으로 돌아가려면 **이 코드 전용의 정식 슬랙 봇 토큰**이
따로 있어야 합니다 (지금 이 대화가 쓰는 연결과는 별개입니다).

1. https://api.slack.com/apps 에서 "Create New App" → "From scratch" 선택
2. 이름(예: 진-DJINN 봇)과 토끼풀 워크스페이스 선택
3. 왼쪽 메뉴 "OAuth & Permissions" → "Scopes" → "Bot Token Scopes"에 아래 권한 추가
   - `chat:write` (메시지 전송)
   - `reactions:write` (👍👎 미리 달기)
   - `reactions:read` (반응 집계)
   - `channels:read` (공개 채널 정보 조회, 선택)
4. 같은 페이지 위쪽 "Install to Workspace" 클릭 → 권한 승인
5. 발급된 "Bot User OAuth Token" (`xoxb-`로 시작) 복사
6. 슬랙에서 `#진-알림` 채널에 들어가 `/invite @봇이름`으로 봇을 초대

### 2. Anthropic API 키 준비

https://console.anthropic.com 에서 API 키를 발급받으세요. 하루 한 번, 새 글
몇 건을 짧게 분류하는 정도라 비용은 매우 적게 듭니다 (한 달에 몇백 원~천 원대
수준으로 예상됩니다만, 실제 사용량은 콘솔에서 확인하세요).

**모델 이름은 꼭 직접 확인하세요.** 이 코드는 모델 ID를 하드코딩하지 않고
환경변수로 받습니다 — https://docs.claude.com/en/docs/about-claude/models 에서
현재 제공되는 모델 중 가장 가볍고 저렴한 것을 골라 아래 3단계의
`ANTHROPIC_MODEL` 값으로 넣으세요.

### 3. GitHub 저장소에 Secrets / Variables 등록

저장소 페이지 → Settings → Secrets and variables → Actions

**Secrets** (탭: Secrets)
| 이름 | 값 |
|---|---|
| `ANTHROPIC_API_KEY` | 2단계에서 발급받은 키 |
| `SLACK_BOT_TOKEN` | 1단계에서 발급받은 `xoxb-...` 토큰 |

**Variables** (탭: Variables)
| 이름 | 값 |
|---|---|
| `ANTHROPIC_MODEL` | 2단계에서 확인한 현재 모델 ID |
| `SLACK_CHANNEL_ID` | `C0BRLQBLGR3` (이미 만들어둔 #진-알림 채널. 다른 채널을 쓰려면 그 채널 ID로 교체) |

### 4. Actions 활성화 및 테스트 실행

저장소의 "Actions" 탭에서 "진(DJINN)-lite 일일 실행" 워크플로를 찾아
"Run workflow"로 한 번 수동 실행해보세요. `#진-알림` 채널에 알림이 오면
성공입니다. 이후로는 매일 한국시간 오전 9시에 자동으로 돌아갑니다.

### 로컬에서 미리 테스트하고 싶다면

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...
export ANTHROPIC_MODEL=...
export SLACK_BOT_TOKEN=...
export SLACK_CHANNEL_ID=C0BRLQBLGR3
python -m djinn_lite.main
```

## 분류 기준 (상/중/하)

`djinn_lite/classify.py`의 `SYSTEM_PROMPT`에 그대로 들어가는 기준입니다. 코드를
열어보지 않고도 편집회의에서 검토할 수 있도록 여기에도 옮겨둡니다.

각 글마다 아래 세 질문에 답해보고 등급을 정합니다.

1. **직접성** — 학생의 권리·의무·일상에 규칙이 바뀌는 수준으로 직접 영향을
   주는가? (교칙·생활규정 제개정, 청소년 대상 법령·조례 제개정과 입법예고,
   청소년을 새로 포함하거나 배제하는 복지·교통·문화 정책, 학교 안전·인권
   관련 사고나 조사, 예산·시설 배정의 공정성 문제라면 "예". 내부 행정 절차,
   인사, 성과평가, 시설 자재 조달처럼 규칙 변화로 와닿지 않으면 "아니오".)
2. **범위** — 서울 소재 청소년 다수 또는 특정 집단 전체에 해당하는가, 소수
   참가자·특정 기관에 국한되는가? (은평구 소재 여부는 따지지 않습니다.
   서울 전역·전국 단위 정책은 지역과 무관하게 범위가 넓은 것으로 봅니다.)
3. **취재 실마리** — 지금 바로 "누구를 인터뷰하고 무엇을 확인하면 기사가
   되는지" 구체적인 각도가 보이는가?

| 등급 | 조건 | 예시 |
|---|---|---|
| 🔴 상 | 직접성이 뚜렷한 "예" + 취재 실마리도 "예" | 학생생활규정·교칙 개정, 청소년 배제 정책의 입법예고, 학교 예산·시설 배정 공정성 문제 |
| 🟡 중 | 직접성은 있지만 간접적이거나 대상이 좁음, 또는 취재 실마리가 아직 흐릿함 | 지원 프로그램 성과 발표, 학생이 지원·참가할 수 있는 기회 정보, 다른 지역 비교 사례 |
| ⚪ 하 | 직접성이 "아니오"에 가까움 | 용역·평가위원 모집, 인사알림, 내부 행정규칙·성과평가 규정 개정, 시설 자재 조달, 성인·유아 대상 프로그램 |

지금은 이 기준 자체가 맞는지 검증하는 단계라 "하"도 전부 슬랙에 올립니다.
`state/feedback_log.csv`가 쌓이면 등급별로 실제 👍/👎 비율을 비교해서, 이
표의 조건 문구를 계속 다듬어나가세요. 예를 들어 특정 유형의 "하"가 계속
👍를 받는다면 그 유형만 따로 "중"으로 승격하는 식입니다.

## 알아두면 좋은 한계

- **페이지네이션 미지원**: 두 게시판 모두 첫 페이지(최신 글 약 10건)만 읽습니다.
  하루 1~3건 정도 올라오는 속도라 매일 실행하면 충분하지만, 글이 갑자기 몰리면
  일부를 놓칠 수 있습니다.
- **사이트 구조 변경에 취약**: 두 게시판 모두 HTML을 직접 파싱합니다. 교육청이
  게시판 디자인을 바꾸면 `djinn_lite/sources.py`의 파싱 로직도 손봐야 합니다.
- **분류는 완벽하지 않음**: LLM 판단은 참고용입니다. 실제 기사화 여부는 반드시
  학생 기자가 원문을 직접 확인하고 결정해야 합니다 — 원본 진 시스템의 윤리
  원칙과 동일합니다.
